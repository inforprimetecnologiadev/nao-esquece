# Não Esquece

Bloco de notas para o celular: texto, checklist, áudios, fotos, pastas, concluídas e lixeira, salvo no aparelho e no Google Drive.

- `site/` — o app (publicado no GitHub Pages em https://inforprimetecnologiadev.github.io/nao-esquece/)
- `site/suporte/` — central de ajuda e contato (formulário que chega por e-mail, via FormSubmit)
- `android/` — o APK nativo: as telas rodam dentro do próprio app (WebView do Android), sem usar o Chrome. Login do Google pela tela de contas do Android, digital/rosto, câmera, galeria, microfone, ditado, salvar e compartilhar pelo Android
- `.github/workflows/` — publica o site e compila o APK a cada atualização

- Versão atual: **1.2.0** (veja o [CHANGELOG](CHANGELOG.md))
- [Central de ajuda e contato](https://inforprimetecnologiadev.github.io/nao-esquece/suporte/) · suporte em até 5 dias úteis
