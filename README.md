# Não Esquece

Bloco de notas para o celular: texto, checklist, áudios, fotos, pastas, concluídas e lixeira, salvo no aparelho e no Google Drive.

- `site/` — o app (publicado no GitHub Pages em https://inforprimetecnologiadev.github.io/nao-esquece/)
- `android/` — o APK, que abre o app em tela cheia pelo Chrome do celular
- `.github/workflows/` — publica o site e compila o APK a cada atualização
